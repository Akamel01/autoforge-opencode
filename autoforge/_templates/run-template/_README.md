# Run template — copy to start new product run

Copy this folder to `.autoforge/stages/` structure is via product side; this template shows empty output scaffolding for a fresh run. The filesystem is the state machine — status is what exists in output/.

Structure to instantiate per new unit of work (one run) in project's `.autoforge/`:
- stages/01_discovery/output/.gitkeep
- stages/02_grill/output/.gitkeep
etc.
